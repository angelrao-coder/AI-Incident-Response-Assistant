
# AI Cybersecurity Incident Response Assistant

## Project Overview

An AI-powered cybersecurity project that analyzes
reported security incidents and generates structured
incident response recommendations using prompt
engineering and a local AI model.

## Features

- Cybersecurity incident classification
- Preliminary risk assessment
- Severity classification
- Dynamic prompt generation
- Local AI model integration
- Incident response report generation
- Containment and recovery recommendations
- Cybersecurity prevention advice

## Technologies Used

- Python
- Ollama
- Llama 3.2
- JSON
- REST API
- Prompt Engineering
- VS Code
- Git and GitHub

## Project Modules

- main.py: Main application
- incident_analyzer.py: Threat classification
- risk_assessment.py: Preliminary severity assessment
- prompt_engine.py: Structured prompt generation
- ai_engine.py: AI model integration

## Installation

Install Python and Ollama.

Download the AI model:

    ollama pull llama3.2:1b

Run the application:

    python main.py

## Supported Incident Categories

- Phishing
- Malware
- Ransomware
- Unauthorized Access
- Data Breach
- Denial of Service

## Disclaimer

This project is for educational and defensive
cybersecurity purposes.

Use fictional incident descriptions only.

The classification is keyword-based, severity
estimates are preliminary, and AI-generated
recommendations require human verification.
